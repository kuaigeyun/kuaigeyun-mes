# 工位机械臂模型（可选）

当前使用程序化机械臂（基座+立柱+横臂）。若需成品工业机械臂 GLB 模型，可手动下载以下推荐来源：

1. **Sketchfab - Low Poly Robot Arm**（CC Attribution）
   - 链接：https://sketchfab.com/3d-models/low-poly-robot-arm-animated-08d3e2e9b7dd4b2db6bb98ccc8b36f32
   - 作者：Myjato
   - 下载 GLB 后重命名为 `workstation-robot.glb`，放入本目录

2. **Poly Pizza - Robot Arm**（CC Attribution）
   - 链接：https://poly.pizza/m/1JbGi41I1l1
   - 作者：Yali Izzo

3. **Get3DModels - Industrial Robotic Arm**（CC Attribution）
   - 链接：https://www.get3dmodels.com/robot/industrial-robotic-arm/

## 使用方式

将下载的 GLB 文件重命名为 `workstation-robot.glb` 并放入 `static/models/` 目录，3D 拓扑将自动使用该模型。若文件不存在，将使用程序化机械臂。
