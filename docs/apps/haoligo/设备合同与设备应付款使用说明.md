# 好力 GO：设备合同登记 / 设备应付款 使用说明

面向采购、财务等业务人员。按本文操作即可完成「登记合同 → 生成应付款 → 提交财务 → 登记付款」全流程。

---

## 1. 这两个菜单分别做什么

| 菜单 | 路径 | 作用 |
|------|------|------|
| 设备合同登记 | 好力 GO → 财务管理 → 设备合同登记 | 登记设备采购合同（供方、合同号、设备、含税价、签订时间、预计交付时间、合同附件） |
| 设备应付款 | 好力 GO → 财务管理 → 设备应付款 | 管理合同对应的应付款：补资料、提交财务、登记/冲销付款 |
| 设备应付款报表 | 好力 GO → 财务管理 → 报表（设备应付款报表） | 汇总查看已付/未付、结清情况（只读查询） |

**重要：** 设备应付款 **不会在登记合同时自动产生**。须在合同列表上点击 **「生成应付款」** 才会生成一条草稿。

---

## 2. 推荐业务流程（一眼看懂）

支持两种节奏，按业务实际选一种即可。

**路径 A：资料齐后再付款（常见）**

```text
① 采购：登记合同（建议填签订时间、预计交付时间）→「生成应付款」
② 采购：补传设备位置 / 发票 / 工程验收单（可随时）
③ 采购：点「提交财务」
④ 财务：登记付款（可分多笔）至结清
```

**路径 B：先付款，后补发票与验收单**

```text
① 采购：登记合同 →「生成应付款」
② 采购：可直接「提交财务」（不必先有发票/验收单）
③ 财务：登记付款
④ 采购：事后在应付款上点「补传资料」，上传发票与工程验收单、补填位置
```

一笔合同 **只能生成一笔** 设备应付款，不可重复下推。

## 3. 角色怎么分工（建议）

| 环节 | 建议角色 | 说明 |
|------|----------|------|
| 登记合同、生成应付款、补传资料、提交财务 | 采购 | 合同与附件由采购维护；发票/验收可晚于付款 |
| 登记付款、冲销付款 | 财务 | 仅「已提交」的应付款可登记付款 |
| 查报表 / 导出 | 采购或财务 | 按权限开放 |

若按钮看不到，请联系管理员开通对应权限（见文末「权限对照」）。

## 4. 设备合同登记

### 4.1 新建合同

1. 进入 **设备合同登记**。
2. 点击右上角 **「登记合同」**。
3. 填写并保存：

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 供方 | 是 | 从供应商中选择 |
| 合同编码 | 是 | 合同编号 |
| 设备名称 | 是 | 采购设备名称 |
| 含税价格 | 是 | 大于 0，保留两位小数 |
| 合同签订时间 | 否 | 合同实际签订日期；列表与详情会展示 |
| 预计交付时间 | 否 | 约定/预计到货交付日期；列表与详情会展示 |
| 合同附件 | 否 | 可上传合同扫描件等；列表中可直接点开下载 |

保存成功后出现在列表中。可用关键词搜索：供方 / 合同编号 / 设备名称。

### 4.2 列表可看什么

除供方、合同编号、设备名称、含税价格外，列表还会显示：

| 列 | 说明 |
|----|------|
| 合同签订时间 / 预计交付时间 | 登记时填写的日期；未填显示为 — |
| 应付款状态 | 未生成 / 草稿 / 已提交 |
| 发票 / 验收单 | 关联应付款是否已上传（未生成应付款时为 —） |
| 已付 / 未付 / 结清 | 来自关联应付款；未生成时为 — |
| 登记人 | 登记合同的人 |
| 合同附件 | 可点击的附件链接（非仅「已上传」标记） |

点 **「查看」** 打开合同详情：基本信息（含签订/预计交付时间）、合同附件、应付款附件概况。

### 4.3 生成应付款（关键步骤）

1. 在尚未生成过应付款的合同行上，点击 **「生成应付款」**。
2. 系统生成一条 **草稿** 应付款，并自动跳转到 **设备应付款** 详情。
3. 若提示「该合同已生成设备应付款」，说明已下推过，请到设备应付款列表查找，勿重复操作。

生成应付款时，会带入合同当时的供方、合同号、设备名、含税价。**签订时间、预计交付时间只保存在合同上**，不会复制到应付款表头。

### 4.4 编辑 / 删除合同

- **编辑**：可改合同信息与附件。  
  - 若关联应付款已 **提交财务**：供方、合同编码、设备名称、含税价 **锁定不可改**（避免与财务数据不一致）。  
  - **仍可修改**：合同签订时间、预计交付时间、合同附件。  
- **删除**：仅当该合同 **尚未生成应付款** 时可删。  
  - 已生成应付款时：须先在设备应付款中删除对应 **草稿**，再删合同；已提交财务的应付款不可删。

### 4.5 导出

有导出权限时，列表工具栏可 **导出** Excel，字段包括：供方、合同编号、设备名称、含税价格、**合同签订时间**、**预计交付时间**、合同附件、应付款状态、发票、验收单、已付、未付、结清、登记人等。

## 5. 设备应付款

本页 **没有「新建」按钮**。单据一律从 **设备合同登记 → 生成应付款** 产生。

### 5.1 列表说明

可见字段包括：供方、合同编号、设备名称、含税价格、设备位置、发票、验收单、已付、未付、结清、提交状态（草稿 / 已提交）。

筛选：

- 关键词：供方 / 合同编号 / 设备 / 位置  
- 状态：草稿、已提交  

### 5.2 补传资料（草稿与已提交均可）

在列表点 **「编辑」**，或详情右上角 **「补传资料」**，可填写/上传：

| 字段 | 是否必须 | 说明 |
|------|----------|------|
| 设备位置 | 否 | 可先付款后补填 |
| 发票附件 | 否 | 可先付款后补传 |
| 工程验收单 | 否 | 可先付款后补传；首次上传时系统记录验收时间 |

**提交财务不再要求** 必须先有发票或验收单。资料可在付款前或付款后任意时刻补齐。

草稿可 **删除**。删除后，对应合同可再次「生成应付款」。已提交或已有付款明细的不可删。

### 5.3 提交财务

草稿状态下点 **「提交财务」**，确认即可（无需附件齐套）。

提交后：

- 状态变为 **已提交**  
- 财务可开始 **登记付款**  
- **设备位置、发票、工程验收单仍可补传**  
- 关联合同的供方 / 合同号 / 设备名 / 含税价锁定；合同上的签订时间、预计交付时间、合同附件仍可在「设备合同登记」中改  

### 5.4 登记付款（可分多笔）

前提：状态为 **已提交**，且 **未付 > 0**。与发票/验收是否已上传无关。

1. 列表或详情中点 **「登记付款」**。  
2. 填写：

| 字段 | 说明 |
|------|------|
| 付款金额 | 必填；不可超过当前未付余额 |
| 付款时间 | 必填 |
| 备注 | 选填 |

3. 保存后：已付增加、未付减少。可多次登记，直至未付为 0（结清）。

### 5.5 冲销付款

在详情抽屉的 **付款明细** 中，对某笔付款点 **「冲销」**（需有登记付款权限）。冲销后未付相应回升。

### 5.6 查看详情

点 **「查看」** 打开详情：合同信息、附件概况、付款明细（已提交后可见）。

### 5.7 导出

有导出权限时可导出列表（含设备位置、发票、验收、已付、未付、结清、提交状态等）。

---

## 6. 设备应付款报表（可选）

菜单：**设备应付款报表**。

用于按合同/供方等查看应付、已付、未付及结清状态，支持导出。  
**不能**在报表里新建或付款，付款仍在「设备应付款」中操作。

## 7. 常见问题

**Q：为什么设备应付款页没有新建？**  
A：应付款必须关联已登记的设备合同，只能从合同「生成应付款」，避免无合同应付。

**Q：合同签订时间、预计交付时间必填吗？**  
A：不必填。建议登记时一并填上，便于列表跟进交付；漏填可事后在合同编辑里补录。应付款已提交后这两个时间仍可改。

**Q：生成应付款后，合同金额改了，应付会变吗？**  
A：生成时会带入当时合同的供方、合同号、设备名、含税价。若应付款仍是草稿且合同未因「已提交」锁定，可先删草稿、改合同再重新生成；已提交后金额类字段不可改。签订/预计交付时间不进应付款，改合同日期不影响已付金额。

**Q：为什么不能登记付款？**  
A：常见原因：未提交财务；或已结清（未付为 0）；或账号无「登记付款」权限。

**Q：为什么不能删除合同？**  
A：该合同已生成应付款。请先删除对应草稿应付款；若已提交财务，应付款不可删，合同也不能删。

**Q：付款能否超过含税价？**  
A：不能。单笔金额不能超过当前未付；累计已付不会超过含税价。

**Q：提交后发现发票传错了怎么办？**  
A：已提交后仍可点「补传资料」更换或增补发票、工程验收单与设备位置。合同金额类字段（供方、合同号、设备名、含税价）提交后仍不可改；签订时间、预计交付时间、合同附件仍可在合同页修改。

**Q：可以先付款再传发票吗？**  
A：可以。提交财务不强制发票/验收；财务登记付款后，采购随时补传即可。

## 8. 权限对照（给管理员）

按角色勾选菜单权限时，可参考：

| 业务动作 | 权限含义（角色矩阵中的能力） |
|----------|------------------------------|
| 查看合同 / 应付款 | 读取 |
| 登记合同 | 设备合同：创建 |
| 改合同（含补签订/交付时间、合同附件） | 设备合同：更新 |
| 删合同 | 设备合同：删除 |
| 生成应付款 | 设备应付款：创建 |
| 补传资料（含已提交） | 设备应付款：更新 |
| 删草稿应付款 | 设备应付款：删除 |
| 提交财务 | 设备应付款：提交财务 |
| 登记付款 / 冲销 | 设备应付款：登记付款 |
| 导出列表 | 对应模块：导出 |
| 看应付款报表 | 设备应付款报表：读取 |

采购建议至少：合同读写删、应付款创建/更新/删除、提交财务。  
财务建议至少：应付款读取、登记付款、报表读取；是否给导出按内控决定。

- [ ] 合同行已点「生成应付款」，进入草稿

- [ ] 已补传工程验收单（如适用）  
- [ ] 未付为 0，或报表中结清状态正确
