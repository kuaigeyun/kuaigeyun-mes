# 好力 GO：厂家外协账号配置说明（管理员）

面向系统管理员。按本文配置后，设备厂家外协账号只能看到本厂家相关的 **设备验收单**（含注塑机验收单，若已授权），机制与模具外协按供应商隔离一致。

---

## 配置总览

```text
① 制造厂商主数据（厂商代号）
        ↓
② 外部角色（合作方类型 = 设备制造商）
        ↓
③ 功能权限（验收读取 / 更新 / 调试等）
        ↓
④ 数据范围 = 自定义（按 manufacturer_code）
        ↓
⑤ 用户绑定对应厂商代号
        ↓
⑥ 厂内开验收单时选对该厂家
```

---

## 1. 先建制造厂商主数据

**路径：** 好力 GO → 设备 → 制造厂商

1. 新增厂家，填写 **厂商代号**、**厂商名称**。
2. **厂商代号** 须稳定：后续用户绑定、验收单厂家编码均依赖此码，勿随意变更。
3. 记下该厂家的 **厂商代号**（例如 `MFR-A`）。

---

## 2. 建「设备制造商」外部角色

**路径：** 系统管理 → 角色

1. 新建角色，例如：`设备厂家外协`。
2. **角色类型** 选择 **外部**。
3. **合作方类型** 选择 **设备制造商**（manufacturer）。
4. 保存。

> 必须是「外部 + 设备制造商」。用内部角色无法走厂家数据范围绑定。

---

## 3. 给角色开功能权限

**路径：** 系统管理 → 角色权限（选中上一步角色）

### 设备验收单（其他设备）建议

| 权限 | 建议 | 说明 |
|------|------|------|
| 读取 | 必开 | 进菜单、看列表与详情 |
| 更新 | 必开 | 填调试内容、上传附件 |
| 调试（submit） | 按业务 | 提交车间试产 |
| 试产（execute） | 一般不开 | 通常由厂内车间执行 |
| 台账结案（complete） | 一般不开 | 厂内结案 |
| 创建 / 删除 | 按内控 | 多数厂家账号不开放 |

### 注塑机验收单

若外协也参与注塑验收，对 **注塑机验收单** 同样勾选读取、更新、调试（按上表裁剪）。

---

## 4. 给角色设数据范围（关键）

仍在 **角色权限** 页的 **数据范围 / 数据权限**：

1. 找到资源：**设备验收单**（及需要的 **注塑机验收单**）。
2. 范围选择 **自定义**（不要选「全部」）。
3. 保存。

系统按厂家维度过滤：单据 `manufacturer_code` ↔ 用户绑定的厂商代号。

| 设置 | 效果 |
|------|------|
| 自定义 | 仅本绑定厂家单据（正确） |
| 全部 | 可能看到所有厂家验收单（错误） |
| 本人 / 本部门 | 不适合厂家外协场景 |

---

## 5. 建外协用户并绑定厂家

**路径：** 系统管理 → 用户

1. 新建用户（账号、姓名、密码等）。
2. **角色** 勾选上一步的外部角色（设备制造商）。
3. 表单出现 **「外部角色-设备制造商绑定」**。
4. 勾选该账号所属厂家（按 **厂商代号**；一般一家一个账号，也可多选）。
5. 保存。

**绑定编码必须与以下一致：**

- 制造厂商主数据中的厂商代号  
- 验收单上所选厂家的编码  

---

## 6. 厂内开验收单时选对厂家

**路径：** 好力 GO → 设备单据 → 设备验收单（或其他设备 / 注塑对应菜单）

1. 新建或编辑验收单。
2. **厂家** 选择该制造商。
3. 按流程推进调试；需要时由外协登录处理本厂单据。

外协只能看到厂家编码落在自己绑定范围内的验收单。

---

## 7. 验收自检清单

用外协账号登录后核对：

- [ ] 能打开设备验收单菜单  
- [ ] 只看到本厂家相关单据，看不到其他厂家  
- [ ] 能保存调试、提交试产（若已授「调试」权限）  
- [ ] 换另一厂家账号，看不到上一家的单据  
- [ ] 厂内账号仍可按原有权限查看相关单据  

---

## 常见问题

| 现象 | 常见原因 | 处理 |
|------|----------|------|
| 外协完全看不到单 | 未绑厂商代号；验收单未选该厂家；角色无「读取」 | 补绑定 / 改单据厂家 / 开权限 |
| 外协看到所有厂家单据 | 数据范围设成「全部」 | 改为「自定义」并保存 |
| 绑定下拉里没有厂家 | 制造厂商主数据未建 | 先维护制造厂商 |
| 能看不能提交试产 | 缺「调试」权限 | 在角色权限中勾选调试 |
| 角色类型选错 | 选成内部角色 | 改为外部 + 设备制造商 |
| 绑定了仍不对 | 厂商代号与单据编码不一致 | 统一主数据代号与单据快照 |

---

## 与模具外协对照（便于培训）

| 项 | 模具外协 | 设备厂家外协 |
|----|----------|--------------|
| 角色合作方类型 | 供应商等 | 设备制造商 |
| 用户绑定维度 | 供应商 / 外协单位编码 | 设备制造商（厂商代号） |
| 单据隔离字段 | 外协单位 / 供应商编码 | 验收单 `manufacturer_code` |
| 数据范围 | 自定义 | 自定义 |

---

## 范围说明

- **已隔离：** 设备验收单、注塑机验收单（按厂家）。  
- **未按厂家隔离：** 设备台账列表本身；若业务要求台账也只显示本厂设备，需另行评估。  

---

*与当前好力 GO 权限、数据范围实现一致。界面文案若有细微差异，以系统实际显示为准。*
