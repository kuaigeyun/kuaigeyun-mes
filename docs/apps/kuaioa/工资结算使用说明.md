# 工资结算使用说明

面向人事、车间统计等业务人员。按本文操作即可完成「开结算单 → 填产线数据 / 导入工资 → 核对明细 → 确认结算」。

菜单路径：**轻办公 → 人事管理 → 薪酬管理 → 工资结算**（部分环境按钮文案为「工资登记」，同一功能）。

---

## 1. 这个功能做什么

按 **车间 + 月份** 做一张工资结算单，把该车间当月在岗人员拉成明细表，自动带出考勤计时、岗位补贴、生活费扣除等，再由您核对、补录后确认。

确认后的金额会用于：

- **个人工资明细**（按人查每月工资）
- **年度工资统计**

**重要：** 上面填的「产线总产量 / 产线总工资」，以及「导入明细」上传的表格，都是为了算进 **本张结算单的人员明细**；填完后必须点 **「按考勤重建」**（产线两项）或完成导入后刷新，数字才会出现在下方表格对应列里。

---

## 2. 推荐操作顺序（一眼看懂）

```text
① 人事：员工档案填好所属车间、计薪方式、小时单价 / 生活费等
② 人事或车间：同车间同月「月度考勤」填完并提交
③ 按需：生活费预支、奖励、岗位补贴先登记好
④ 工资结算：点「工资登记 / 新建」选年月、车间 → 保存后进入明细
⑤ 有产线计薪人员：填「产线总产量」「产线总工资」→ 点「按考勤重建」
⑥ 需要批量补基本工资 / 计件：点「导入明细」上传 Excel
⑦ 核对表格数字 → 点「确认结算」锁定
```

没有考勤或档案车间不对时，明细会空或计时为 0，页面上也会有黄条提示，按提示补资料后再点「按考勤重建」。

---

## 3. 怎么开一张结算单

1. 进入 **工资结算** 列表。
2. 点右上角 **「工资登记」**（或「新建工资结算」）。
3. 填写：

| 项目 | 说明 |
|------|------|
| 年月 | 要结算的月份 |
| 车间 | 本单只结算该车间人员（与员工档案「所属车间」一致） |
| 用工类型 | 可不选（表示全部）；可选正式工 / 临时工等缩小范围 |
| 加班倍率 | 计时加班工时用的倍数，一般按公司规定填 |

4. 保存后会 **自动进入结算明细页**。

也可在列表点某行的 **「结算明细」** 进入同一页面。

---

## 4. 明细页上方：「产线总产量」「产线总工资」是干什么的

这两项 **只给「计薪方式 = 产线」的员工用**。  
员工档案里若是「计时 / 计件 / 月薪」，填这两项 **不会** 改他们的工资算法。

| 填写项 | 您填什么 | 点「按考勤重建」之后，体现在哪里 |
|--------|----------|----------------------------------|
| **产线总工资** | 本月该产线 / 车间要拿来分的 **工资总额**（元） | 按每人当月考勤工时占比，分到对应人员明细的 **「计时工资」** 列 |
| **产线总产量** | 本月产线 **总产量**（件数 / 产量数，按现场统计口径） | 系统按产量×默认月奖比例算出一封奖金池，再按工时占比分到 **「补助奖励」** 列 |

### 操作步骤

1. 确认相关人员在员工档案中 **计薪方式选「产线」**，且本月考勤已提交（有工时才能分摊）。
2. 在明细页上方填入 **产线总产量**、**产线总工资**（可只填工资总额；产量按是否做产线奖填写）。
3. 点击工具栏 **「按考勤重建」**。
4. 在下方表格中查看：产线计薪人员的 **计时工资**、**补助奖励** 是否已按工时摊开；页面顶部 **应发合计** 会随之更新。

### 容易误解的三点

1. **只填数字、不点「按考勤重建」→ 表格不会变。**
2. **不是每人再填一遍产量。** 上面填的是整线总量，系统按工时比例自动分到每个人。
3. **若车间里没有「产线」计薪人员**，填这两项后重建，明细里也看不到明显变化——请先改档案计薪方式。

---

## 5. 「导入明细」要上传什么文件

导入 **不是** 上传合同、考勤扫描件之类附件，而是上传一张 **Excel 工资补录表**，用来批量写入某一列金额。

### 文件要求

- 格式：`.xlsx` 或 `.xls`
- 表头必须有两列（可用中文）：
  - **姓名**
  - **金额**
- 姓名须与本结算单明细里的员工姓名一致
- 金额大于 0 的行才会导入

示例：

| 姓名 | 金额 |
|------|------|
| 张三 | 1200 |
| 李四 | 800 |

### 操作步骤

1. 在结算明细页点 **「导入明细」**。
2. 在弹窗里选择要写入的项目：
   - **基本工资**，或
   - **计件工资**
3. 点 **「选择 Excel 文件」**，选好表格。
4. 成功后关闭弹窗，在下方明细表对应列查看金额。

**说明：** 计时、生活费扣除、夜班/高温补贴等多数项由考勤、档案、补贴单自动带出；导入主要用于补 **基本工资** 或 **计件工资**。也可不导入，直接在表格格子里手改。

---

## 6. 明细表各块大致含义（核对时看这些列）

不必逐项背公式，核对时抓住这些即可：

| 区域 | 常见列 | 从哪里来 |
|------|--------|----------|
| 应得 | 计时工资、计件工资、夜班/高温/岗位津贴、补助奖励、基本工资等 | 考勤×单价、绩效、补贴登记、产线分摊、导入或手改 |
| 扣除 | 生活费扣除、房租电费、保险、请假、个税等 | 档案标准 + 当月预支、请假扣款等；个税等可手改 |
| 结余 | 结余工资、打卡金额 | 系统汇总；打卡金额可手改 |

页面上方会显示本单 **应发合计 / 扣除合计 / 结余合计**。  
若有人结余低于公司维护的最低工资，会有黄条提醒，请再核对。

---

## 7. 确认与改数

| 操作 | 何时用 |
|------|--------|
| **确认结算** | 明细核对无误后点击；确认后锁定，不能再随便改 |
| **重新打开** | 已确认但发现错了，需要改回草稿再改 |
| **按考勤重建** | 改了考勤、档案、产线总产量/总工资、补贴等之后，用最新数据重算明细（会覆盖自动计算部分，手改/导入过的请重建后复查） |
| **打印** | 需要纸质签字时使用 |

确认后的数据才会稳定进入 **个人工资明细**、**年度工资统计**。

---

## 8. 常见问题

**Q：产线总产量填了，表格里哪里能看见？**  
A：先点 **「按考勤重建」**，再看计薪方式为「产线」的员工行里的 **「补助奖励」**（以及填了总工资时的 **「计时工资」**）。顶部合计也会变。

**Q：上传什么文件？合同 PDF 可以吗？**  
A：不可以。这里只要 **Excel**，且列名是「姓名」「金额」，用来补基本工资或计件工资。

**Q：明细是空的 / 计时全是 0？**  
A：先查员工档案是否填了所属车间；再查同月同车间考勤是否已 **提交**；再查档案是否有小时单价（计时人员）。改完后点「按考勤重建」。

**Q：计件工资一直是 0？**  
A：计件依赖已确认的绩效汇总，且员工档案需关联系统用户。未做绩效时可手改或用「导入明细」写入计件列。

**Q：和「生活费发放登记表」是一回事吗？**  
A：不是。生活费发放表看的是档案生活费标准 + 预支；工资结算是完整应发/扣除/结余。两边可同时使用，用途不同。

---

## 9. 权限说明（按钮看不到时）

若看不到「工资登记 / 确认结算 / 导入」等按钮，请管理员在角色权限中为对应人员开通 **工资结算（薪酬）** 相关权限（查看、新建、更新、提交等）。

产线车间下拉若为空，还需具备车间的 **查看** 或 **回显** 权限（由管理员在角色矩阵中勾选）。
