# 快视觉现场联调手册

> 通用产品说明，不含客户公司名与报价条款。对照 ROADMAP P3。

## 1. 相机与光源

- SDK：优先 GenICam / 海康 MVS / Basler；第三方整机用 `external_only` + 入站转发。
- 曝光：先固定增益，再调曝光时间，保证灰度不过曝、不过暗。
- 光源：漫射或同轴按零件表面选择；避免环境光闪烁导致帧间抖动。

## 2. 激光测厚

- 通道优先激光位移；方案参数配置 `tol_min` / `tol_max` / `unit`。
- 接线：传感器到 IPC 串口或 TCP；边缘 Agent 用 `laser_serial` / `laser_tcp`（P2+ 适配器）。
- 标定：用量块确认读数与实测一致后再发布方案。

## 3. 触发

| 模式 | 说明 |
|------|------|
| `manual` | 仅外部/脚本触发 |
| `interval` | 定时采集（实验室 POC） |
| `gpio` | 现场光电/脚踏；P2 可用软件短间隔模拟 |

发布方案后在边缘节点点「使配置生效」，或等待 Agent 下一拉取周期。

## 4. 边缘节点

1. PC 新建节点 → 复制 Token  
2. 编辑 `edge-agent/config.yaml` 的 `base_url` / `device_token`  
3. `python agent.py config.yaml`  
4. 视觉中心看心跳；停进程后应在离线秒数内显示离线  

弱网：断网后本地 SQLite 缓冲，恢复后 batch 续传（幂等靠 `event_id`）。

## 5. 样本与模型

- 检测记录「入库为样本」→ 样本库导出 `*-pack.json`（图片 object_key + 标签）。  
- 训练在仓外完成；ONNX 上传到模型制品并绑定到方案草稿版本后再发布。  
- 步骤类若勾选「需模型」，未绑定不可发布。

## 6. 推荐 IPC 规格（附录，可选）

| 项 | 建议 |
|----|------|
| CPU | 8 核及以上工业主板 |
| 内存 | ≥16 GB |
| 存储 | ≥256 GB SSD（原图本地缓冲） |
| 系统 | Linux x86_64 / Windows IoT，Python 3.11+ |
| 网络 | 千兆有线到工厂交换机 |

以上为工程参考，不构成商务承诺。
