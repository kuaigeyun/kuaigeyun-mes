# 轻财务总账（对标用友 U8 / 金蝶云星空）

## 一句话边界

一期总账 = 单账套科目+辅助核算 + 凭证（制单→审核→记账）+ 结转损益/结账 + 科目余额表/明细账/总账/辅助账 + 轻量银行对账 + 应收应付（及供应链）按模板生成凭证并月结对账。

二期总账 = 一期闭环打磨 + 辅助维度扩展（职员/项目）+ 凭证字收/付/转 + 现金流量表 + 期末转账/摊销预提可配置执行 + 出纳加深（日记账/票据轻量），仍落在 `kuaicaiwu`，不另起应用。

## 对标来源

用友 U8 / U8 Cloud「财务会计-总账」、金蝶云星空/KIS「总账」中型制造标配。不另起应用，能力落在 `kuaicaiwu`。

## 日常闭环

`初始化（科目/辅助/期初）→ 制单 → 审核 → 记账 → 期末转账/结转损益 → 结账 → 账表查询`

## 结账顺序（业务先、总账后）

固定资产（若有）→ 应收 → 应付 → 存货/成本 → **总账**。

## 职责划分

| 需求 | 归属 |
|------|------|
| 凭证、科目余额、结账、标准账表 | 总账（本模块） |
| 客户核销、账龄、对账 | 应收应付（finance） |
| 原材料/产成品数量金额 | 存货/成本 |
| HaoliGO 开票核销/设备应付 | 独立，不并入总账科目真源 |

## 凭证状态机

`draft（制单）→ reviewed（审核）→ posted（记账）`；`cancelled（作废）`。  
已记账不可改，须反记账后修改。审核可用参数要求制单人≠审核人。

## 余额真源

科目余额表仅由 **记账 / 反记账 / 期初录入** 写入。查询「含未记账」时临时叠加 draft/reviewed，不写余额表。

## 一期菜单

应用侧栏一级（对标主流财务会计模块顺序）：

1. **总账核算**：会计科目、总账选项、期初余额、记账凭证、账簿查询、期末处理、出纳对账  
2. **往来核算**：应收/收款/销项发票、应付/付款/进项发票、核销、对账、预收预付、银行账户  
3. **成本管理**  
4. **经营分析**

### 账簿查询菜单位置与同步

- 侧栏：**快财务 → 总账核算 → 账簿查询**
- 路由：`/apps/kuaicaiwu/gl-management/books`
- 权限：`kuaicaiwu:gl:read`
- 菜单真源：后端 `apps/kuaicaiwu/manifest.json`（`app.kuaicaiwu.menu.gl-management.books`）
- 若侧栏缺失：执行应用菜单/权限同步后刷新浏览器；确认角色已授予 `kuaicaiwu:gl:read`

## 一期非目标（已由二期承接或仍排除）

原一期不做：多账簿/多准则、独立出纳全功能、银企直联、现金流量精细、摊销预提全套、合并报表、存货数量金额明细塞进总账科目树。

其中现金流量标准表、摊销预提轻量台账、出纳日记账/票据加深、职员/项目辅助、收付转凭证字 → **二期交付**。

## 二期边界

| 能力 | 二期做法 |
|------|----------|
| 一期打磨 | 账簿/凭证导出打印；辅助客商部门 Select；转账模板 UI；仓储确认写存货会计事件 |
| 辅助核算 | 职员（User）、项目（总账项目字典）；科目开关 + 分录/余额键 |
| 凭证字 | 记/收/付/转，按字分号（参数可关回退仅「记」） |
| 现金流量 | 现金流量项目字典 + 凭证行归集 + 账簿「现金流量表」；真源=已记账凭证 |
| 期末 | 转账公式（余额/发生额/固定额）可视化；摊销预提台账生成凭证 |
| 出纳 | 日记账联查凭证、支票领用/核销轻量、调节表导出；**无银企** |
| 固定资产 | 事件类型与凭证模板占位；有 OA 资产模块时可挂折旧/处置事件 |

## 二期仍明确不做

多账簿/多准则、银企直联、合并报表、存货数量金额明细塞进总账科目树、HaoliGO 并入总账科目真源、固定资产全生命周期折旧引擎（仅钩子/占位）。

## 命名

总账凭证 UI 称「记账凭证」；收付款业务单不改称总账凭证。

## 会计科目预置

- 入口：会计科目页「导入标准科目模板」→ 弹窗选择模板 → `POST /gl/accounts/seed?template_key=...`
- 模板清单：`GET /gl/accounts/seed-templates`
- 当前内置（中国标准，一级 4 位编码，`4-2-2-2`）：
  - `cas_manufacturing` 企业会计准则（工业制造）— 默认推荐
  - `cas_commerce` 企业会计准则（商品流通）
  - `cas_service` 企业会计准则（服务业）
  - `sbas_general` 小企业会计准则（通用）
- 行为：按编码幂等；已存在跳过；账套编码规则若非 `4` 开头则对齐为模板规则
- 下级明细（如应交税费二级）导入后按需手工增设

## 业财事件 → 凭证模板

| 事件类型（节选） | 模板 | 说明 |
|------------------|------|------|
| 销货/应收、收款、预收 | sales_delivery / receipt / prepayment | 供应链与往来已落事件 |
| 进货/应付、付款、预付 | purchase_receipt / payment / prepayment | 同上 |
| 销项/进项发票 | sales_invoice / purchase_invoice | 发票创建写事件 |
| INVENTORY_* / WAREHOUSE_* / COGS_* | inventory_receipt / inventory_issue / cogs_transfer | 其他出入库确认写事件；数量金额真源仍在存货/成本 |
| FA_DEPRECIATION / FA_DISPOSAL | fa_depreciation / fa_disposal | 二期模板占位 |

生成入口：凭证页「按事件生成」→ `POST /gl/vouchers/generate-from-events`。
