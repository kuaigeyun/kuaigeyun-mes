# 交付项目 P1 后续 Backlog（装备制造协同）

> 本期（迭代 A+B）已完成：节点/子任务时间与负责人可运营、开始/完成节点与里程碑门禁、节点单据挂链、临期/逾期站内信与交付中心预警区。  
> 以下 P1 项**不纳入本期编码**，作为下一阶段立项参考。

## 优先级 P1

### 1. 制造执行联动：工单回写节点进度

- 节点「机加/装配」支持自动或半自动关联/下推工单
- 工单完工事件显式回写节点进度（禁止读侧猜进度、禁止静默覆盖已审汇报）
- 需定义：`work_order.completed` → `delivery_project_node` 进度事件契约与 manifest 权限

### 2. 采购联动：长周期件承诺日

- 关键件/长周期件到货承诺日挂到采购相关节点
- 缺料风险灯影响装配节点预警（复用 `DeliveryProjectAlertService` 扩展规则）
- 禁止读侧 JOIN 采购单补交期

### 3. 质检联动：发运里程碑门禁

- 调试/出厂检验单挂里程碑节点（扩展 `DeliveryProjectNodeDocument` 或检验专用关联）
- 未合格不得完成「发运」类里程碑（门禁策略可租户配置）
- 与现有 `quality_inspection` 挂链类型对齐 Linked 抽屉

### 4. 变更与基线

- 客户改需求/设计变更后，分析对冻结里程碑之后节点的影响
- 影响采购在途、在制工单的可视化（非通用 PM 依赖网络）
- 需基线快照表与变更单关联，禁止 alias 映射旧状态

### 5. 问题升级闭环

- `DeliveryIssue` 增加「阻塞里程碑」标记
- 升级路径：质量/工艺/供应商（消息规则 + 工作台待办前缀 `delivery_project`）

## 建议落地顺序

1. 工单回写进度（对交机链路拉动最大）
2. 质检门禁发运里程碑
3. 采购承诺日与缺料风险灯
4. 变更基线与问题升级

## 明确不优先（P2 或更晚）

- 通用 WBS 无限拆解、FS/SS 全功能依赖网络
- 独立 BI 替代现有三张交付报表
- 与 OA 请假等无关审批强耦
