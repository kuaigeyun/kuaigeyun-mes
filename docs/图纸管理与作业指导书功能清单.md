# 图纸管理与作业指导书 功能清单

> 所属应用：**主数据管理（master-data）**  
> 菜单路径：工艺资料 → 图纸管理 / 标准操作 (SOP)

---

## 一、图纸管理

### 1.1 模块概述

工程图纸（Engineering Drawing）模块用于管理零件图、装配图、工艺图等 CAD/文档资料，支持 PLM 风格的修订版生命周期，并与物料、工艺路线、工序、BOM 建立关联，供车间执行、物料详情、研发项目等场景消费。

| 项 | 说明 |
|---|---|
| 模块码 | `process:drawing` |
| 菜单路径 | `/apps/master-data/process/drawings` |
| 数据表 | `apps_master_data_engineering_drawings` |
| 编码规则 | `ENGINEERING_DRAWING_CODE`（默认：TZ + 日期 + 序号） |

### 1.2 功能清单

#### 基础资料管理

| 功能 | 描述 |
|---|---|
| 新建图纸 | 创建草稿，填写图号、名称、修订版（默认 A）、类型、主文件、附加页、关联对象、备注 |
| 编辑图纸 | 仅 **草稿（Draft）** 状态可编辑 |
| 删除图纸 | 软删除；仅 **草稿** 或 **已作废（Obsolete）** 可删 |
| 图纸详情 | 查看基础信息、关联物料/路线/工序、文件预览、自定义字段、修订历史 |
| 图号自动生成 | 按编码规则生成图号，支持手动输入 |
| 自定义字段 | 支持租户级扩展字段 |

#### 文件管理

| 功能 | 描述 |
|---|---|
| 主文件上传 | 单份主图纸文件，存入文件中心（`core_files`） |
| 附加页上传 | 支持多份补充页/附图 |
| 支持格式 | PDF、DWG、DXF、STEP/STP、PNG、JPG/JPEG |
| 文件分类 | `engineering_drawing` |

#### 版本与生命周期

| 功能 | 描述 |
|---|---|
| 修订版管理 | 同一图号下多修订版并存，唯一约束：图号 + 修订版 |
| 发布 | 草稿发布为 **已发布（Released）**；同图号其他已发布版自动作废 |
| 作废 | 已发布版手动作废，可填写作废原因 |
| 升版 | 从已发布版创建新修订草稿，修订号自动递增（A→B→…→Z→AA） |
| 修订历史 | 按图号查看全部修订版时间线 |
| 列表视图 | **现行有效版**（每图号一条）/ **全部修订版** |

**状态流转：**

```
草稿 (Draft) → 发布 → 已发布 (Released) → 作废 → 已作废 (Obsolete)
                ↑
            升版（从已发布版创建新草稿）
```

#### 分类与导航

| 功能 | 描述 |
|---|---|
| 图纸类型 | 零件图、装配图、工艺图、其他 |
| 左栏导航树 | 按 **类型 / 状态 / 物料 / 工艺路线** 四种维度筛选 |
| 列表筛选 | 关键字（图号/名称/备注）、类型、状态、物料、路线、工序 |
| 排序分页 | 支持分页与排序 |

#### 关联能力

| 功能 | 描述 |
|---|---|
| 关联物料 | 多选物料 UUID |
| 关联工艺路线 | 多选工艺路线 |
| 关联工序 | 多选工序 |
| 关联 BOM | STP 导入后可关联 BOM 根物料及版本 |
| 上下文查询 | 按物料/路线/工序查询 **已发布** 图纸（供其他模块调用） |

#### 预览

| 功能 | 描述 |
|---|---|
| 内嵌预览 | 宽屏右栏预览 PDF、图片、DWG、STEP |
| 大图预览 | 弹窗全屏查看 |
| 行选联动 | 点击列表行切换预览内容 |

#### STP 装配 BOM 导入（装配图专属）

| 功能 | 描述 |
|---|---|
| STP 解析 | 从 STEP/STP 装配结构解析子件层级 |
| BOM 导入 | 导入为工程 BOM，可自动创建缺失子物料 |
| 关联回写 | 导入后回写 BOM 根物料及版本、最近导入时间 |
| 跳转设计器 | 导入完成后可跳转 BOM 设计器继续维护 |

#### 下游消费

| 场景 | 描述 |
|---|---|
| 物料详情 | 展示该物料关联的已发布图纸，可跳转详情 |
| 工单工序文档 | 工位/工单执行时聚合展示已发布工程图纸 |
| 工位机 / 移动 MES | 工序文档 Tab 中查看工程图纸 |
| PC 图纸查看器 | Kiosk 模式独立查看 |
| 快研发（KuaiPLM） | 研发交付物「图纸包」深链至本模块 |

### 1.3 权限清单

| 权限码 | 说明 | 状态 |
|---|---|---|
| `master-data:process:drawing:read` | 查看列表、详情、修订历史、上下文查询 | ✅ |
| `master-data:process:drawing:create` | 新建、升版 | ✅ |
| `master-data:process:drawing:update` | 编辑草稿 | ✅ |
| `master-data:process:drawing:delete` | 删除 | ✅ |
| `master-data:process:drawing:release` | 发布 | ✅ |
| `master-data:process:drawing:obsolete` | 作废 | ✅ |
| `master-data:process:drawing:import` | STP 装配 BOM 导入 | ✅ |
| `master-data:process:drawing:export` | 导出 | ⚠️ 已声明，无 API |
| `master-data:process:drawing:submit/approve/audit/reject/revoke/print` | 单据审核流 | ⚠️ 已声明，实际走 release/obsolete |

### 1.4 核心业务规则

- 图号存储为大写；同租户下图号 + 修订版唯一
- 仅草稿可编辑；仅草稿或已作废可删除
- 发布时同图号其他已发布版自动作废
- 升版仅能从 **已发布** 版创建
- 上下文查询仅返回 **已发布** 且未删除的图纸
- 文件仅存 UUID，二进制由文件中心统一管理

## 二、作业指导书（标准操作 SOP）

### 2.1 模块概述

标准操作（SOP）模块用于维护数字化作业指导书，支持富文本说明、流程化 eSOP 设计、节点附件、报工数据采集项，并按物料/物料组/工序维度匹配，供车间工位、移动 MES、报工等场景使用。

| 项 | 说明 |
|---|---|
| 模块码 | `process:sop` |
| 菜单路径 | `/apps/master-data/process/sop` |
| 数据表 | `apps_master_data_sops` |
| 子页面 | 设计器、执行页、Kiosk 查看器 |

### 2.2 功能清单

#### 基础资料管理

| 功能 | 描述 |
|---|---|
| 新建 SOP | 创建作业指导书，填写编码、名称、版本、工序、绑定关系等 |
| 编辑 SOP | 修改基础信息与内容 |
| 删除 SOP | 软删除 |
| SOP 详情 | 查看基础信息、绑定关系、富文本内容、附件、自定义字段 |
| 列表查询 | 支持关键字、工序、物料、物料组、工艺路线等筛选 |
| 自动编码 | 按编码规则页生成编码 |
| 自定义字段 | 支持租户级扩展字段 |
| 启用/停用 | 批量或单条切换 `is_active` |
| 导入/导出 | CSV 模板批量导入与导出 |

#### 绑定与匹配

| 功能 | 描述 |
|---|---|
| 绑定工序 | 每条 SOP 关联一道工序 |
| 绑定物料 | 可绑定一个或多个具体物料 |
| 绑定物料组 | 可绑定物料组，覆盖组内物料 |
| 载入工艺路线 | 可关联工艺路线作为来源 |
| BOM 载入模式 | 按物料 / 按物料组 / 指定 BOM 三种模式 |
| 重复绑定校验 | 同一物料或物料组 + 工序 不可重复绑定 |
| 匹配优先级 | 具体物料+工序 > 物料组+工序 > 仅工序 |

#### 批量创建

| 功能 | 描述 |
|---|---|
| 按工艺路线批量创建 | 按「物料/物料组 × 每道工序」批量生成 SOP 草稿 |
| 自动命名编码 | 批量创建时自动生成名称与编码 |

#### 内容与附件

| 功能 | 描述 |
|---|---|
| 富文本内容 | 支持图文说明 |
| 全局附件 | SOP 级附件列表 |
| 版本字段 | 字符串版本号（非完整 PLM 修订流） |

#### eSOP 数字化设计器

| 功能 | 描述 |
|---|---|
| 流程画布 | 基于 ReactFlow 的 ProFlow 设计器 |
| 节点类型 | 开始、工步、检验、结束 |
| 工步配置 | 名称、描述、工步要点 |
| 节点附件 | 每节点可上传图片/PDF/DWG/DXF/STEP/Excel/MP4 等 |
| 报工数据采集 | Formily 表单配置：数字/选择/文本/日期时间 + 校验规则 |
| 保存配置 | `flow_config` + `form_config` 写入 SOP 记录 |

#### SOP 查看与执行

| 功能 | 描述 | 状态 |
|---|---|---|
| eSOP 分步展示 | 解析 `flow_config`，按工步展示要点与附件 | ✅ |
| SOP 执行页 | 步骤进度 + Formily 表单填写 | ⚠️ 后端 API 已移除 |
| Kiosk 查看器 | 独立 URL 打开（`sopUuid` 或 `operationId`） | ✅ |
| PC 工单 Kiosk | 作业指导书弹窗 | ⚠️ 部分 mock |

#### 车间消费（快制造）

| 功能 | 描述 |
|---|---|
| 工序文档聚合 | SOP + 工程图纸 + 物料图片 + 工单附件合并展示 |
| ESOP 工步查看 | 工位机：工步/要点/备注/附件 |
| SOP 阅读确认 | 开工前确认已阅读 SOP |
| 工单角标 | 工单列表显示 ESOP/图纸存在性标识 |
| 报工参数采集 | 报工时采集 SOP 配置的 `sop_parameters` |
| 移动端文档 | 移动 MES 工单文档区 + ESOP 查看 |

#### 研发侧关联（快研发）

| 功能 | 描述 |
|---|---|
| 交付物类型 | NPI 阶段「作业指导书包」，类型 `sop` |
| 工程变更 | 支持 `sop_change` 变更类型 |
| 深链跳转 | 从研发项目跳转至主数据 SOP 模块 |

### 2.3 权限清单

| 权限码 | 说明 | 状态 |
|---|---|---|
| `master-data:process:sop:read` | 查看列表、详情 | ✅ |
| `master-data:process:sop:create` | 新建 | ✅ |
| `master-data:process:sop:update` | 编辑、设计器 | ✅ |
| `master-data:process:sop:delete` | 删除 | ✅ |
| `master-data:process:sop:import` | CSV 导入 | ✅ |
| `master-data:process:sop:export` | CSV 导出 | ✅ |
| `master-data:process:sop:submit/approve/audit/reject/revoke/print` | 单据审核流 | ⚠️ 权限已声明，UI 未接入 |

**车间侧权限：**

| 权限码 | 说明 |
|---|---|
| `kuaizhizao:production-execution-terminal:read` | 工位工序文档、SOP 确认 |
| `kuaizhizao:work-order:*` | 工单侧文档 API |

### 2.4 核心业务规则

- SOP 必须关联工序；物料/物料组绑定可选但参与匹配
- 同一物料（或物料组）+ 同一工序 不允许重复绑定
- 车间匹配优先级：具体物料 > 物料组 > 仅工序
- 工位文档 API 为 ESOP 聚合的唯一真源入口
- SOP 执行实例表仍在，但后端 API 已移除

## 三、两模块对比

| 对比项 | 图纸管理 | 作业指导书 (SOP) |
|---|---|---|
| 核心对象 | 工程图纸文件 + 修订版 | 操作步骤 + 报工采集项 |
| 版本机制 | Draft / Released / Obsolete | 字符串版本号 + 启用/停用 |
| 主要格式 | CAD / PDF / 图片 | 富文本 + 流程节点 + 多媒体 |
| 车间展示 | 图纸文档预览 | ESOP 分步引导 |
| 特殊能力 | STP 装配 BOM 导入 | eSOP 设计器 + 报工参数 |
| 生命周期 | release / obsolete | is_active 启用/停用 |
