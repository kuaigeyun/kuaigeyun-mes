# MRP 计算参数：一页纸说明（面向客户）

**适用对象**：计划、采购、生产负责人及企业管理层  
**产品能力**：统一需求计算（MRP）在创建/执行时可配置下列参数，使**建议量与开工/到料时间**更贴近中小制造企业的现场与现金流。

---

## 一、我们帮您解决什么问题？

| 痛点 | MRP 参数如何对应 |
|------|------------------|
| 算出来的采购/投产时间和仓库、在途对不上 | **参与计算的仓库**、**在途/在制**、**预留**、**安全库存**、**再订货点** — 把「手里有什么、路上有什么、要扣什么」说清楚。 |
| 远期预测不准，算进去反而误导下单 | **计划展望期（天）** — 只纳入交期在合理窗口内的需求，聚焦近期可执行计划。 |
| BOM 经常改版，怕用错版本 | **BOM 版本** / **按物料指定版本**、**最大展开层级** — 控制用哪套清单、展开多深。 |
| 供应商有起订量/整包装，系统建议量下不出去 | **按批量规则调整建议量**（结合物料主数据中的最小量、倍数、上限，并可全局覆盖）。 |
| 物料提前期填了仍偏紧，希望整体多留余地 | **排程缓冲天数** — 在物料来源提前期基础上，开工/请购再往前多留若干天（应对波动）。 |

**说明**：采购/自制/委外的**基础提前期**在物料「来源配置」中维护；本次运算参数是在此之上的**策略与缓冲**，不改变物料主数据本身。

---

## 二、参数一览（解决什么问题）

| 参数（概念名） | 解决什么问题 |
|----------------|--------------|
| 考虑安全库存 | 净需求计算时是否扣除安全库存策略，避免过度依赖库存。 |
| 考虑在途/在制 | 是否把未结案采购、在制工单等计入供应，减少重复请购/投产。 |
| 考虑预留量 | 线边等已预留数量是否从可用量中扣除。 |
| 考虑再订货点 | 是否按再订货点规则放大净需求。 |
| 参与计算的仓库 | 哪些仓库的库存参与汇总（默认普通仓；可按业务增选）。 |
| 计划展望期 | 超出展望期的需求行可不参与本次运算，减少远期噪声。 |
| BOM 版本与展开层级 | 用对 BOM、控制展开深度，避免错料与性能风险。 |
| 建议量按批量规则 | 建议采购/工单数量是否按最小量、倍数、上限圆整，便于直接下单。 |
| 排程缓冲天数 | 在提前期基础上整体前置开工/请购日，留出现场波动空间。 |
| 产能/齐套等（若界面有） | **当前版本不参与净算与建议量**，供后续排程扩展；以产品说明为准。 |

---

## 三、落地建议（中小企业）

1. **先保证四类主数据**：BOM（含版本）、物料来源与提前期、仓库与库存入账习惯、开放采购单/工单状态准确。  
2. **先开「展望期 + 仓库范围 + 在途」**，再按需打开安全库存、再订货点。  
3. **批量规则**与供应商/工艺确认后再启用，避免与现场「凑单」习惯冲突。  
4. **缓冲天数**宜小步调整（如 1～3 天），结合历史延期数据迭代。
